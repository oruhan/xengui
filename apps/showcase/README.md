# XenGui Showcase

The repository's visual reference application. It is deliberately built only
with XenGui widgets, the `xenframe` runtime, and icons from `xengui-icons`.

```bash
cargo run -p xengui-showcase
```

The app demonstrates retained rendering, responsive flex layout, runtime
state, keyboard-focusable controls, Material Symbols, theme roles, text input,
progress, sliders, switches, and GPU-backed composition in one screen.

The screenshot in the workspace README is captured from this executable; it
is not a design mockup.
